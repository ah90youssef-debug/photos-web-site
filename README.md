# 📚 Teachers Manager – مشروع ويب لإدارة صور مدرسين

## 📁 هيكلية المشروع
```
photos website/                # مجلد المشروع (المسار الذي تم إنشاؤه)
│
├─ app.py                     # تطبيق Flask الرئيسي
├─ requirements.txt           # مكتبات بايثون المطلوبة
├─ Start.bat                  # تشغيل الخادم المحلي ونفق Cloudflare
├─ Stop.bat                   # إيقاف كل الخدمات بأمان
├─ README.md                  # هذا الملف (التوثيق)
│
├─ static/                    # ملفات الواجهة الثابتة
│   ├─ style.css              # تنسيقات (CSS) للصفحة – RTL, مبسطة
│   └─ app.js                # سكريبت لتأكيد حذف
│
└─ templates/                 # قوالب Jinja2 للواجهة
    └─ index.html            # الصفحة الرئيسية العربية
```

## 🚀 كيف تشغّله؟
1. **تثبيت المتطلبات** (مرة واحدة):
   ```bat
   python -m pip install -r requirements.txt
   ```
2. **تثبيت Cloudflare Tunnel** إذا ما كان مثبتًا:
   - نزّل `cloudflared.exe` من https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation
   - احفظه في مسار موجود ضمن متغيّر `PATH` أو في نفس مجلد المشروع.
3. **إعداد كلمة مرور المسؤول** (اختياري):
   - يمكنك تعيين متغيّرات البيئة `ADMIN_USER` و `ADMIN_PASS` قبل تشغيل البرنامج:
   ```bat
   set ADMIN_USER=admin
   set ADMIN_PASS=admin123   :: استبدل بكلمة سر أقوى
   ```
   - إذا لم تُعيّن هذه المتغيّرات، سيُستخدم `admin / admin123` كافتراضي.
4. **تشغيل المشروع**:
   - نفّذ ملف `Start.bat`:
   ```bat
   Start.bat
   ```
   - سيبدأ السيرفر على ‎`http://localhost:5000` ويُنشئ نفقًا علويًا عبر Cloudflare. ستحصل على رابط عام (مثل `https://xxxxxx.trycloudflare.com`). هذا الرابط يُمكن مشاركته مع أيّ شخص للوصول إلى التطبيق.
5. **إيقاف المشروع** عندما تنتهي:
   ```bat
   Stop.bat
   ```
   - يوقف كل من Flask و `cloudflared` بامان.

## 🛡️ الأمان
- **توثيق أساسي** باستخدام HTTP Basic Auth. سيُطلب اسم المستخدم وكلمة المرور عند إضافة/تعديل/حذف بيانات.
- **تحقّق من نوع وحجم الصورة** (مسـمح بامتدادات PNG, JPG, JPEG, GIF، الحد الأقصى 2 MB).
- **الوصول للملفات** مقصور على مجلد `D:\TeachersManager`؛ لا يُسمح بالوصول إلى أي مسار آخر.

## 📂 التخزين الدائم
- جميع الصور تُحفظ في `D:\TeachersManager\images`.
- قاعدة البيانات SQLite تُحفظ في `D:\TeachersManager\database.db`.
- عند تشغيل التطبيق مرة أخرى، تُحمّل جميع البيانات تلقائيًا.

## 📎 ملفات تم إنشاؤها
- **app.py** – خادم Flask مع جميع المسارات المطلوبة (قائمة، إضافة، تعديل، حذف).
- **requirements.txt** – حزم Python الضرورية.
- **templates/index.html** – الواجهة العربية المتجاوبة (RTL).
- **static/style.css** – تصميم بسيط، متجاوب، ألوان مريحة للعين.
- **static/app.js** – حوار تأكيد الحذف.
- **Start.bat** – تشغيل Flask + Cloudflare Tunnel + فتح المتصفح تلقائيًا.
- **Stop.bat** – إيقاف كلا العمليتين بأمان.
- **README.md** – هذا الدليل.

🔧 **ملاحظة**: إذا رغبت في تعديل كلمة المرور أو مسار التخزين، عدّل القيم في `app.py` أو عيّن المتغيّرات البيئية قبل التشغيل.

🖱️ **استخدام**: بعد تشغيل `Start.bat`، استبدل الرابط الذي يولده `cloudflared` برابطك الخاص وشاركه مع زملائك. سيُشاهد الجميع نفس البيانات في الوقت الحقيقي.
